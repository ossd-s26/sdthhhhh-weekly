This week I feel I understand Git much better than before. In Lecture 1, when we explored the `.git` folder, it was very interesting for me. Before this class, I only knew how to type commands like `git add` and `git commit`, but I did not really know what Git was doing internally. Now I understand that Git saves snapshots and that the staging area is an important step. Reading *Pro Git* also helped me connect theory and practice.

In Lecture 2, we talked about project evaluation. After reading the materials, I realized choosing an open source project is not only about what looks cool. We need to think about how active the community is, whether documentation is clear, and if beginners are welcome. Some projects looked exciting but also a little scary because the codebase is big.

I am most excited about working on a real open source project because it feels meaningful. It is different from just finishing homework. My biggest challenge might be confidence and understanding a large project. Sometimes I worry that I am not good enough yet. But I plan to start from small tasks, read carefully, and learn step by step.
